# Introduction

Sens-O-Matic is a backend API for coordinating spontaneous meetups with
friends. It turns "Who's up for drinks?" into an actual hangout with minimal
friction: it collects structured availability, finds the time overlaps
algorithmically, and reduces the back-and-forth messaging.

The [specification](specification.md) is the full description of the
application.

This book holds the high-level documentation and the usage. The technical
detail is in the docs of the code: run `cargo doc --open` for the module docs
and the function docs.
